# MATHS NOTATION

**All maths is LaTeX.** In text fields write it inside `$…$` (e.g. `$x^2 + 5x + 6 = 0$`, `$\angle ABC = 90^\circ$`, `$\triangle ABC$`). In a `formula` field write bare LaTeX without `$`. Never leave `x^2`, `\sqrt`, `\frac` or Greek letters outside `$…$` — they would show as raw code.
- Fractions inside a sentence: `$\dfrac{a}{b}$` (full size), not `\frac`, so they stay readable on screen.
- NCERT forms: `S_n = \dfrac{n}{2}[2a + (n-1)d]`, `a_n = a + (n-1)d`, `\sin\theta`, `\sqrt{2}`, `\overline{AB}`, `\angle`, `\triangle`, `\parallel`, `\perp`, `\cong`, `\sim`, degrees as `^\circ`.
- Numbers exactly as the source gives them; decimals and fractions not converted unless the step does it.

**Theorem + proof.** A `theorem` slide states the result (for geometry: Given and To prove too); the next slide is its `proof` — 2–6 steps, each a reason ("Triangles on the same base and between the same parallels") plus the statement it gives. A proof longer than 6 steps continues on a second `proof` slide titled "… (continued)". Prove only what NCERT proves.

**Worked examples** (`solved_example`): the problem restates all given values; steps go formula → substitution → simplification; the answer is one clear result (with unit where there is one). Use `tip` for the common mistake NCERT's context suggests (a sign error, forgetting $\pm$, the wrong formula) or an alternative method.

**Say it, don't show LaTeX in narration.** The voice-over reads maths in words: "x square plus five x plus six equals zero", "a n equals a plus n minus one into d", "root two", "angle A B C". No `$`, backslashes or symbols in narration.

**Figures are images.** Constructions, graphs, geometric figures and number lines come from the catalog — never describe a figure as a run of text lines; put it on a `labeled_diagram`, `definition`, `proof` or `solved_example` slide.
