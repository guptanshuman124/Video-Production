# SLIDE LANGUAGE — HINDI (this course)

This is a Hindi-subject course, so the **on-screen slide text is in Hindi (Devanagari)**: titles, definitions, points, table cells, questions and options. Quote poem lines, prose passages, names and terms exactly as the source gives them — never translate a quoted line.

The voice-over is in Hindi too (see LANGUAGE — HINDI): explain in simple spoken Hindi, and when you read a quoted line aloud, keep it in Devanagari exactly as written.
