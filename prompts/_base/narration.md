# REVEAL MARKERS

Slides build up while the teacher talks: each block appears at the moment the narration reaches it. You mark those moments with **markers** written inside the narration: `{{b1}}`, `{{b2.1}}`, `{{b1.2.1}}` …

- For each slide you get the exact list of markers it needs, in order, and what each one reveals. Use **every** listed marker **exactly once**, **in the listed order**. Never invent, skip, rename or repeat a marker.
- Put a marker **immediately before** the sentence that starts talking about what it reveals. The block appears on screen a quarter of a second before that sentence is spoken.
- Give every reveal its own explanation: at least one full sentence after a marker before the next marker.
- Anything that has no marker (the title, an image, a question and its options, an assertion, a problem statement) is already on screen when the slide starts — talk about it from the beginning.
- On question slides the first marker is the answer reveal. Before it: read the question, ask the student to think (end a sentence with "?"), give them a moment, then reveal.
- Markers are the only non-speech text allowed. No stage directions, no [pause], no SSML, no markdown, no bullet points.
